# Word交付与开题文书适配

在G0确定交付配置、G4组织正文、G6检查文件时使用。先读 [官方样例与依据边界](proposal-format-sources.md)：开题的文书形态、学校要求、学位层次及学位类型影响格式，不能只按学科确定一套字号和引用制。无模板时的通用方案是有依据的适配生成，不是一份跨学校固定模板。

## 选用顺序

1. 用户上传的适用模板及已知正式要求优先；核对栏目、表格、字数、编号、页式和引用，保留必要结构。导师或用户选择与正式要求冲突时按routing.md说明具体差异。
2. 未上传模板但已知学校/院系时，可查当前适用的公开开题规范；只有确认文书类型、层次与专业适用才采用。不把学位论文或其他学校格式自动视作本校开题规范。
3. 没有本校可用模板或明确要求时，按下述文书形态与层次组合建议结构，查找与本题学位类型、专业路径相近的官方开题样例；说明哪些借鉴、哪些是本次编辑选择。不套另一校标识/签章，不把其全部行政规定移植过来。没有可访问的相近样例时用最低限度的建议配置完成，记录依据缺口，不捏造“学科标准”。不以未提供模板为由等待，不逐项询问字号等常规设置。

默认成品是正文和参考文献完整、可编辑的.docx。用户明确只要文字、Markdown或其他格式时服从该次要求。PDF可按需附加，不能代替默认Word；不默认交付PPT或额外制图文件。

## 先识别文书形态

| 形态 | 采用条件与处理 |
|---|---|
| 表格式报告书 | 本校提供栏目/审核表时，在原表填写，保留必要基本信息和审批空间；长内容按原表续页或附件要求处理，不强压单页，不套三线数据表来替换行政表 |
| 正文报告式 | 无指定表格、主要要求连续论证时使用，组织题目/基本信息、主体与文献；是否独立封面、摘要、目录、预算依实际要求，不照搬完整学位论文前置页 |
| 组合材料 | 正式要求报告书附独立综述、评审表或申请表时分别准备或按指定顺序合并；正文研究现状不自动替代独立综述。导师意见、成绩和签名留空，不能由skill代填审批结论 |

未知学校且未指定形态时，本科任务默认采用带基本信息区、网格正文栏目及必要填写空间的表格式建议版；硕博结合适用样例选择报告书封面加正文、表格式或组合材料，不机械把长篇论证塞进本科小表。该默认是本技能的交付选择，不是高校共同标准。用户明确要连续正文时服从，正文型也须处理适用的基本信息。若层次、学位类型未知且会改变结构深度，在关键交互中一并核实，先继续可独立进行的检索；不静默认定本科或硕士。

## 基本信息与表单完整性

博士沿用带基本信息与意见空间的正式报告书体验。无校表且用户未另选时，优先形成基本信息表加可续页的完整论证栏目，或信息/评审表与关联正文的组合材料；不要因博士文本较长退回省略信息栏的裸正文，也不为网格外观压缩博士论证。实际校表或用户明确格式覆盖该建议。内容深度按 [博士要求](doctoral-quality.md)，表单外观不能替代内容验收。

在首轮把学校、院系及模板情况与学位层次合并了解；已知学校优先找适用正式表，而不是只找论证指导。学校名称同时是检索线索和文档字段；姓名、学号等通常在定稿前集中补齐，无须阻塞文献与研究设计。不要求用户为了启动任务提供个人身份资料，用户不愿提供时保留可填写空栏。

无校表的建议版，按实际任务设置学校、学院/系、专业/方向、年级/班级、姓名、学号、指导教师、课题名称与填表日期；硕博按需要设置学位类型等。已知值填入，未知字段留空或在编辑稿标“待填写”，不把制作日期自动当作真实填表/开题日期，不补造校名、姓名、导师、校徽和公章。

正文在选题依据/研究现状、问题目标与内容、方法方案、条件与风险、预期成果、进度、文献等栏目中保持完整论证。栏目可合并或细分，不能为了表格外观删去学科必需的设计细节。长栏目采用可延展单元格、续表或明确关联的附件，不以固定行高截断文字，不强压为一两页。行政表网格与正文内部的数据三线表分别处理。

正式模板中的导师意见、开题小组/院系意见、成绩、签名和日期按原表保留，供有权人员填写；无模板时可设置简洁的导师意见和审核意见预留区，不照搬另一学校的特殊审批流程、承诺书或章戳。留出空白不等于捏造审批。把未知基本信息和正常待签审批与未完成研究正文区分：前者应在交付说明列出；学生信息未补齐时只能称内容及排版完成、基本信息待补，不能称已可直接提交。

## 无本校模板时的结构配置

以下为参考F1—F7并结合既有学科指导的综合建议，不是照抄原校栏目。选择与本题相符的一行，必要时组合，篇幅由用户任务与内容决定；博士不只把硕士文本拉长。

| 类型 | 主体论证任务与必要适配 |
|---|---|
| 本科研究论文 | 选题理由与价值、相关研究及切入点、拟研究问题与内容、材料和方法、可行性、论文拟定框架、进度和文献；研究现状可并入立题。论文框架是未来论文提纲，不是开题目录；F1/F6只作差异样例，学年论文不能冒充毕业论文规范 |
| 本科工程/设计实践 | 问题与需求约束、相关技术/案例、设计目标与内容、候选方案及选择、实施与验证、资源风险、进度和文献；根据学科说明拟交付对象，不能用完成作品/系统功能代替研究问题 |
| 学术学位硕博 | 立题与研究现状、问题/假设与目标、研究内容、证据与方法/设计、可行性与已知基础、关键难点及应对、拟贡献、进度和文献；摘要、独立综述、预算等依正式要求或对论证的必要性采用，不一律添加。博士需强化原创问题、证据链及总体研究安排，按真实层次指导补查 |
| 专业学位 | 从实际问题和专业情境定位，说明应用价值、问题及内容、材料/案例与方法、评价、实施条件、难点和进度；临床病例研究、MBA和工程专硕不能互套同一结构，按本专业指导补查。F3的三级论文大纲只作该MBA样例，不强加所有专硕 |
| 文史哲法论证路径 | 在对应层次中突出研究史、概念与理论、史料/文本/规范范围、分析或考证与反论、论文论证框架；没有实验任务时不设“实验材料/仪器”空栏目 |
| 艺术与设计研究 | 区分学术研究、创作/设计实践及混合路径；按题目安排案例/调研、研究或创作问题、方案过程、评价与成果形态。F7只支持设计学学术型示例，开题不等于毕业作品集，不因艺术学科自行改为方形画册 |

各主学科指导中的表达要求继续适用。实验、公式、量表、图版、档案注释等按实际研究方式呈现；不依学科大类直接锁定作者—年份、顺序编码或脚注体系。优先采用正式要求，其次相近适用的开题指导与本专业有据习惯，仍无依据时选全篇一致、可核对的体例并标为本次建议。采用某个命名标准及版本前核实具体条文。

## 页面配置按来源逐项落实

在工作记录形成一份简短配置：文书形态、栏目/附件、页面和装订、正文与标题样式、编号、引用/注释、图表/公式、页码/目录；每项区分正式要求、已核实参考或本次编辑选择。来源未规定不等于可以声称已符合来源；相互矛盾时核对原附件或适用说明，不拼接成伪规范。

F1与F2的页码要求不同，F2与F3字号/引用也不能归并为统一方案。撤销所有任务统一2.54厘米页边距、16/14磅标题、连续页码及按学科固定引用制的规则。

无具体规定时允许使用以下最低限度的编辑起点完成文件：A4、中文宋体小四和适用西文字体，正文1.5倍行距，页边距上/下/右2.5厘米、左3厘米；标题采用与正文协调的加粗层级而非夸张展示字号。这里的行距和页边距等组合是本次建议，不是从样本归纳出的共同标准；可以根据文书类型和实际内容调整，并记录最终值。有本校规定即覆盖。

正文报告式无页码要求时可加连续页码便利审阅；表格式保留原模板规定，不擅加页码或目录。数据表可用三线表，行政表保留原有网格；图题通常下置、表题通常上置，按选定来源覆盖。图表/公式依内容需要设置编号，明确来源、单位与解释。字体不可用时记录替代并检查缺字；外文开题另核对语言与版式要求。

## Word交付验收

- **内容一致**：Word含确认后的完整正文及书目，章节、数字、图表和引用与定稿一致，未残留Markdown符号、工具引用标记、批注或内部检查记录。
- **可编辑**：正文是真实段落、标题为样式、表格为原生表格；公式按需原生编辑，不以整页图片或PDF嵌入冒充Word。
- **格式对应**：核对本次适用模板要求，或上述通用版式与选定学科呈现配置。行政填写位与研究主体占位分开；不捏造封面信息。
- **表单完整**：检查基本信息字段及已知值、各正文栏目、适用的意见/签名空间及续页关联；表格边框真实可编辑。未知身份字段集中列出，不因未知而整块删除。正文内容完整与行政信息待补分别报告，正常待签栏不伪填为已批准。
- **实际页面**：渲染并逐页查看最新版本，检查缺字、字号、编号、图表裁切、跨页、页码、标题孤行及大片异常留白；字段/目录要核对实际显示值。结构检查不能代替逐页核查。
- **交付状态**：正文和页面均完成适用检查才能称Word成稿。只生成文件或仅检查内部XML时，仍为排版核查未完成稿。工具确有障碍时保留完整内容与已生成文件，说明具体缺口并继续解决，不静默改交Markdown后宣称达成Word目标。

默认仅交最终.docx及简短说明；文本备份、PDF或检查记录按需提供。建议格式说明放在交付消息中，不污染报告正文。内容合格与排版合格分别判断，漂亮页面不能抵消未解决的科学缺陷。
