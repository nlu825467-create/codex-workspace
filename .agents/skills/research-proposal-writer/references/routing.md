# 学科与研究方式路由

具体匹配步骤及本次写法、结构、格式和标准的组装规则见 [学科匹配与执行方案](discipline-execution.md)。自动处理用户已给的学科/专业，不把内部选择任务转交用户。

从题目、材料和用户意图提取：学科/子领域、层次、问题类型、对象、资料或数据、分析/干预方法、结论性质、条件和要求。区分已知、推定与未定。

先读 [学科索引](disciplines/index.md) 中适用的具体指导，再选择下表的方法分支。执行顺序是“学科论证任务 → 当前研究路径 → 适用方法 → 课题具体操作与标准”。学科指导规定应论证什么及怎样组织写作，方法指导规定怎样形成可信证据；两者都要落实。

不要只根据“机制”“影响”“优化”等词决定方法。题目写“影响”不代表具有因果识别设计。结合问题和方法先例判断。

| 实际任务 | 分支 | 注意 |
|---|---|---|
| 解释文本、史料、历史过程或话语 | humanities.md | 原始材料、语境、竞争解释 |
| 测量分布、关系、效果或计量分析 | quantitative.md | 描述、相关、预测、因果分开 |
| 理解经验、意义、过程和情境 | qualitative.md | 认识立场、研究者位置、材料生成 |
| 操控条件检验机制或做实验探索 | experimental.md | 对照、独立重复、可解释结果 |
| 人群健康、病例和诊疗研究 | clinical.md + 相关方法 | 人群、结局、伦理和可用性 |
| 算法、系统、工程或计算模拟 | engineering.md | 需求、基准、验证和约束 |

## 组合与覆盖

分支是研究方式指导，不是六大学科模板。教育、经济、地理、农学等按实际研究组合，并补充本领域方法规范。混合研究解释：为何组合、各自回答什么、先后或并行、何处整合、结果冲突如何解释，不能拼接两份独立方案。

法教义学、哲学论证和艺术实践已有基础学科路径，可以独立执行，不必强选问卷或实验。数学统计虽有基础路径，但纯数学/统计理论的专门依据仍需补充。系统综述等特殊方法、索引明确为延伸的子方向及未列领域，需要检索当前领域高校指导和原始方法资料，形成补充流程与验收依据，对齐后继续。来源不足时说明边界，不强套最近分支，不自称支持所有学科。

法学可为规范解释、制度比较或实证；计算机可为证明、实验或用户研究；文学可为文本或数字人文。学科提供背景，实际研究决定操作。

## 层次与要求

以当前培养要求和用户选择为准，不编造统一字数或创新门槛。未给要求时，本科控制范围并体现方法掌握，硕士强调独立完成明确问题，博士需要更强原创论证；这些是设计参考，不是一律要求突破理论。

记录要求原文/位置、来源、日期、适用范围及硬性程度。正式要求、导师要求、用户偏好实质冲突时展示差异并请用户决定处理方式。不让旧范例覆盖新规定。用户选择偏离模板时记录差异，不再声称完全符合模板。
