# 学科匹配与执行方案

用户给出“选题＋学科＋专业方向”后，自动完成匹配。用户不需要知道文件名、方法分支或内部分类。这里的自动匹配由模型依据输入和指导做语义判断，不是假定存在已经训练或验证的分类器。

## 匹配与路径选择

1. 原样保留用户学科和专业方向，依据 [学科索引](disciplines/index.md) 查找主指导。可按名称、同义称谓和对象检索，但不能仅凭关键词定方法。
2. 专业方向用于细化本学科路径。例如课程教学论应落到教学问题，结构工程关注荷载、模型和验证，护理学不自动采用机制实验。
3. 题目决定当前研究问题及证据性质；与用户学科一起确定贡献面向。数字人文以文学/历史论证为主，计算为辅；教育管理不能仅因“管理”两字改成企业管理。
4. 主指导原则上一个，必要时组合辅指导和方法分支。若尚有多条同样合理的实质研究路线，先检索后给选项，让用户选研究路线，不让用户选择内部文件。
5. 没有精确专业指导或现有文件标明需补证时，自主检索该方向的高校开题/研究计划指导与原始方法依据，先补足差异再执行。不能只取最近大类就宣布匹配完成。

仅题目也可启动，学科未给时先推定并在影响方向时核实。三项齐全且无实质歧义时直接匹配，不重复询问已给信息。用户明确改变所属方向或研究目标时重新匹配并撤销受影响的旧设计。

博士不能因25领域索引有条目就视为专门标准已齐全。在本次执行方案中明确“子领域＋博士类型＋拟作主张”，核对现有指导的来源层次；本科、硕士或招生指导可辅助组织流程，不能独自支持博士内容通过。补查当前适用培养/开题要求、最接近原始研究和本题方法依据，形成能识别本题失败的具体标准。无公开校级细则不必停工，可依据领域研究构建建议标准并标明；缺少关键学科知识不能用已读通用博士指导替代。

## 先把学科匹配变成写作差异

匹配完成后，用当前课题回答以下问题，写进已有执行方案即可，不另建一套审批表。答案来自实际阅读与适用要求；无法判断的关键项先补查，不由学科名称推定。

| 要确定的差异 | 本次执行需改变什么 |
|---|---|
| 研究对象与判断类型 | 研究的是文本意义、历史过程、规范理由、解释关系、性能还是专业决策；相应采用解释、考证、证明、识别、评价等路径 |
| 文献中的比较单位 | 比较论证与前提、史料与解释、模型与识别条件、技术方案与约束，或实践方案及其实施条件；不是统一逐篇摘要 |
| 合格的依据 | 哪些原始文本、材料、数据、推理或验证能支持核心判断，什么依据只能辅助，如何处理最有力的不同意见 |
| 知识或专业认识增量 | 完成后准备改变哪项已有理解或专业选择，什么发现意味着没有推进；不把所有领域都写成变量机制或效果提升 |
| 成文组织 | 各部分怎样推进这项判断，哪些概念/材料必须先交代，反论、边界和评价放在哪里；依论证任务映射学校栏目 |
| 成稿验收 | 从本题最可能失败之处选检查，例如版本误读、反例未回应、选择偏差、基线不公平、只改进作品未产生学习；不能只验收方法是否执行 |

同一大类内部也要区分路径：哲学史解释与规范辩护、教育史与课堂干预、算法证明与工程应用不共用一套关键论证。跨学科时指出最终贡献面向谁，辅助方法如何服务主问题，避免两套目录拼接。

以当前题目做一次反向检查：如果只替换学科名称，材料选择、综述比较、关键段落和验收判断都不变，回查是否只有标签适配；确有共享方法可以保留，不能为了显得不同制造无依据的学科差异。该检查是写作诊断，不是自动分类评分。

## 每次生成一份内部执行方案

在开始详细研究设计前组织以下内容；长任务保存进工作记录，短任务在上下文维护，不必额外生成大量文件。

| 项目 | 本次必须落定的内容 |
|---|---|
| 匹配依据 | 用户原始学科/专业、题意、主辅指导、相关路径和匹配理由 |
| 研究层次 | 实际学位层次、学术/专业类型、开题阶段、报告准备期限与整个论文周期；博士加载 [博士内容指导](doctoral-quality.md)，不得默认沿用本科规模与计划 |
| 写作方法 | 学科中的实际工作顺序、综述组织法、核心论证/设计任务及成文方式 |
| 输入安排 | 已有材料、自主检索项、必要用户决定，材料缺失的替代路线 |
| 报告结构 | 各章/栏目及论证任务，来自正式要求或明确标注的建议 |
| 交付格式 | 文件类型、篇幅安排、标题编号、引用体系、图表/公式/注释及页面样式 |
| 验收标准 | 通用、学科、方法及当前专业/课题标准，检查依据与失败处理 |
| 交互计划 | 哪些决定已给定，后续何时展示方案供用户选择 |

如果只能写“按通用模板完成”而没有学科论证差异，匹配尚未落实。学科建议结构见对应文件末尾；它是起点，要根据路径和正式模板调整，不是强制目录。

## 格式与标准的来源

学校、院系、专业/学位及导师要求应按适用范围核对；用户有具体选择则落实，实质冲突按 routing.md 呈现差异处理，不隐藏偏离。

没有正式格式时，采用学科文件的论证指导，并按 [Word文书适配](word-format.md) 结合层次、学位类型及用途选择表格式/正文式/组合材料，查相近官方开题依据，逐项确定默认可编辑.docx的结构、附件、页面及引用/注释、图表与公式呈现。区分参考依据和本次编辑选择，不能称学科统一规定；不编造国家/学校标准或一律套某刊格式，不把学科名称当成唯一版式依据。常规编辑项不逐一向用户索取选择，实质内容和研究决定仍按节点交互。

用户只提供学校名称时可查公开的当前适用文件，但核实层次、专业、日期与文书类型；学位论文格式不自动等于开题格式，其他学校申请proposal不能直接代替本校规定。未找到也能完成建议格式报告。

## 执行与验证

对用户简短说明“将按哪个学科/专业路径组织，以及采用何种格式依据”，随后进入检索与阶段工作。自动匹配不取消研究切入点、设计和内容重点的交互。

G0核对匹配与格式来源，G1—G3落实学科论证方法，G4核对结构和篇幅，G5查内容是否仍符合路径，G6核对实际交付文件与格式。每阶段同时用已生成方案核查，不以读过指导代替应用。
