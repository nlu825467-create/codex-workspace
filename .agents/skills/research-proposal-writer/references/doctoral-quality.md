# 博士开题的内容生成与验收

主要服务博士学位研究开题；在博士任务的G0—G6持续使用，叠加具体学科和方法指导。不是把本科文本加长，也不是博士申请文书。学位类型、开题阶段及学校要求未明时先核实，已有信息不重问；可以并行检索，不将“面向博士”写成未知用户的身份事实。依据与外推边界见 [博士要求来源](doctoral-sources.md)。

## 1 先确定研究层次与真实边界

初轮合并了解学术/专业博士、学校与专业方向、研究所处阶段、开题节点和剩余研究期限。用户可选提供导师意见、重要文献、已有成果、材料入口及资源；不要求先交完整综述、理论框架或预实验才能开始。由skill先提出有依据的路线，用户决定重点及现实取舍。

区别“准备开题报告的几周”与“完成整篇博士研究的周期”。短期调查、一次比较或一项试验可能只是前期工作，需说明它在整体论文中的作用，不能沿用本科16周计划充当博士全程。

学术博士重点论证相对已有知识的原创推进；专业博士按实际学位要求论证复杂专业问题、实践创新与可审查的研究贡献，不能退化成常规实施记录。不同类型不互相降低要求，也不把基础理论建构强加给所有应用研究。层次明确为本科或硕士时按其要求执行，不强套博士门槛。

两类博士同等覆盖，不设置主次路径。下列是本技能的适配原则，具体成果形态与标准须按专业和本校要求补查：

| 共同论证任务 | 学术博士的类型重点 | 专业博士的类型重点 |
|---|---|---|
| 问题定位 | 相对已有知识的关键难题、争论或解释局限 | 真实复杂实践问题及现行方案的局限，为什么需要博士层次的研究 |
| 预期贡献 | 原创解释、方法、证明、材料或规范论证及其知识后果 | 实践创新及其研究贡献，明确适用条件；不以项目完成或一般建议代替 |
| 比较与证据 | 最接近研究、竞争解释及支持新认识的证据链 | 同时比较相关研究与现行实践方案，说明创新方案、评价依据、实施约束与迁移边界 |
| 整体研究 | 各研究/章节共同支撑总体知识贡献 | 实践问题、研究过程、创新形成和评价组成完整博士论证；不机械要求项目都含干预循环 |

不把学术博士统一等同于纯理论研究，也不把专业博士统一等同于做产品、干预或项目。专业指导缺失时自主补查对应专业博士规范和相近研究，不能只复用学术博士标准后换名称。基础材料可选的原则对两类相同；尚未落实的机构资源与现场权限都按真实状态处理。

两类重点有重叠，不构成“学术博士只产理论、专业博士只看改善”的二分。专业博士仍须论证原创研究或既有知识原创应用的认识价值，学术博士也可在真实实践中形成原创贡献。专业任务在G1—G5同时加载 [专业博士研究与评价](professional-doctorate.md)，再结合具体学科，不将MBA等硕士应用要求直接升格为DBA等博士标准。

## 2 G1 先建立学术定位而非资料清单

围绕选题追踪核心概念/理论、关键争论、最接近的研究及适用前沿。优先核查会改变立题判断的原始材料；综述和高被引不是权威结论的替代品，近期也不自动比奠基工作重要。

在已有阅读记录中加入最接近工作对照：各自提出什么主张，凭什么材料或论证成立，适用什么条件；本题保留或改变什么，为什么差异值得研究。按争论和证据组织，不机械国内/国外逐篇介绍。关键比较必须读到相应正文、证明、史料或规范条文；只有摘要时只用已知内容，不据此宣布对方缺少机制、忽略情境或本题有原创性。查不到的关键材料继续找公开版本或替代原始来源，不能只靠免责声明放行。

将“从未研究某地/人群”与“现有认识在特定条件下面临需要解释的难题”分开。场景或案例差异可以承载原创性，但要说明其理论、历史、规范或实践判别意义，不能只因换地方就成立。既有研究已经回答的问题，应转向有证据支持的进一步问题，而非继续使用空白修辞。

G1到G2的证据须落实在一段可回查的主题综合：哪些已核实研究支持或挑战何种认识，差异可能来自对象、材料、理论前提还是设计，本题为何仍有问题。资料不一致未必是理论悖论；先排查概念和条件不等同，不为制造博士问题把不同指标/场景硬写成矛盾。没有真实争论也可以提出有价值的新问题，不必伪造理论冲突。

## 3 G2 先推敲博士问题与预期贡献

形成简短的研究主张：现有认识是什么 → 哪一重要问题仍未充分解决及其依据 → 本题准备推进什么认识 → 通过什么研究形成判断 → 哪些结果会使该主张收缩或修正。没有必要硬造假设或预测结果；解释性、人文和规范研究可用论题、概念区分与竞争论证表达。

核心检查：如果本题按计划完成，领域读者会对什么改变理解或判断？“识别因素、丰富研究、提出建议、完善流程”只是产出描述，须进一步说明增加了哪项认识、修正什么解释或使哪项复杂实践判断成为可能。单纯应用成熟方法、换一个数据集或整理常见障碍，尚不足以说明博士研究潜力。

预期贡献可以体现为理论解释或边界修正、方法/证明创新、具有解释后果的新材料、新的规范论证、复杂专业问题中的可验证实践创新等，不规定统一种类和数量。每项主张对应已有工作、拟议证据和适用范围；“创新点”应从正文论证中推出，不能写完后另造三点。开题论证的是有根据的原创潜力，不要求已经获得原创结果，也不承诺必然突破。

分别审查“与已有工作有何不同”和“这个不同为什么值得研究”：新工具、新场景或新组合可能新而不重要，重大现实问题也可能缺少研究增量。方法复现可以有原创认识价值，但须指出拟解决的证据争议或新判断，不能把复现规范性本身充当贡献。

将拟贡献再转成一个能被证据支持、挑战或仍无法判断的具体命题/论题，说明相对最接近工作会改变哪项解释或实际选择。增加因子、拼接理论、组合方法或换行业本身不是这一判断。区分行业/地区是进入场域还是解释条件；只研究某场域的一般问题时，不擅改用户题目，但在范围与贡献中避免宣称行业特有机制。若最可能得到的几种结果仍只能复述已有认识，返回定位与设计，不靠加长创新段落补足。

把问题形成过程写成简短的比较论证，保存在已有记录并转成正文，不为每句背景设表：

1. 复原最接近工作的具体回答及成立条件，标明读到的原文位置。先假设它已能回答本题，检查本题还有什么真正未定。
2. 指出仍未定的判断及其后果：若得到不同回答，哪项解释、概念区分、材料认识或专业选择会改变？“还没人研究本校”不足以回答。
3. 比较仍符合用户选题的合理切入点，结合证据可得性、认识价值和整篇论文规模推荐；保留确有依据的单一路线，不凑数。
4. 将推荐问题连到决定性研究任务，考虑支持、挑战与无法判断的情形。阴性结果或反例只有在设计能形成明确认识时才有价值，不能预先许诺任何结果都是贡献。

此时只能论证原创潜力，不将检索未发现直接等同领域从未研究。若最接近工作已经包含拟议区分或方案，明确继承什么，重新定位尚未完成的推进；无法找到实质增量就返回阅读与问题设计。贡献段只总结已经在立题和设计中论证的内容。

提出真正可行的研究切入点供用户选择。涉及改变对象、核心问题或整体范围时解释影响再对齐，不能悄悄把原题升级成另一个题目；也不把贡献设计工作全部推回给用户。定位不足时返回阅读和问题设计，不能以“用户不追求创新”“只是方法训练”放行博士内容。

## 4 G3 让理论与方法承担判断任务

理论或概念工具应解释对象、定义重要区别、支持材料选择和分析，而非单列名词。若没有独立理论框架的必要，说明研究依赖的概念前提、论证传统或技术原理即可；不为所有博士统一加一章大理论。

关键概念须说明本题中的含义、研究层级和如何在材料/测量/推理中辨认，区分相近概念与价值前提。例如主观感知不能自动代替实际制度安排，个体叙述不能直接当组织机制，规范价值判断不能由观察频率直接推出。引入一个理论后，说明它具体改变了哪项取证、分析或论证选择；删去名称而设计完全不变时，先检查它是否只是装饰，再补足作用或删除，不机械判所有理论都须导出变量。

按实际采用的理论核对原始定义及必要后续修正，再把核心概念连到材料、分析单位和判别方式；不能以看似相近的代理材料直接等同理论对象。关键理论只读一份奠基文献仍不足以辨认本题概念时，定向补读，而非堆叠理论名称。

若称能区分竞争解释，具体列出哪些观察支持、挑战或仍不能区分它们，检查共同变化、研究者介入等替代解释；仅与机制相容的证据不要写成已识别机制。材料可以组成有用的证据组合，但不能未经理论论证把“理想时同时观察到”改写为每项必须同时变化的必要条件。

为核心问题落实“主张/待解问题—子任务或章节—证据/材料—推理与分析—判断依据—主要替代解释—失败应对”。相邻任务可合并，不强制多方法。方法精确执行只能说明规范性，还要解释为什么这套证据能推进核心问题。

先标明核心问题要形成的是描述、解释、因果、预测、规范评价、证明、设计或实施等何种判断，再选择设计。至少把最关键的一条“证据为什么支持主张”讲清：将看到/获得什么，怎样分析，凭什么排除或回应有分量的不同解释，何种材料仍无法判断。描述性材料不因加了高级分析软件就成为机制证据。暂时无法区分时调整主张或补设计，不靠预填结论解决。

| 研究路径 | 博士设计需要进一步回答的实质问题 |
|---|---|
| 定量、因果与干预 | 若主张因果，识别策略及其假设如何成立，主要替代解释如何处理；测量、层级、误差与结论范围是否相配。描述或预测任务不硬套因果识别 |
| 质性与解释研究 | 案例/情境为何有助于研究问题，概念怎样帮助理解材料；竞争解释、差异和反例如何改变分析；深描如何形成解释增量。单案例可以成立，不因博士身份机械加样本、纵向或混合方法 |
| 实验、机制与临床 | 关键证据能否区分目标解释与替代解释，对照、时序、测量和验证分别承担什么任务；不凭多个相关指标声称完整机制 |
| 算法、工程与模拟 | 与最接近方案的差别为何重要，理论/方法或复杂约束下的改进依据是什么；基线、评价、成本和适用条件怎样支撑主张，不能把程序细节与公平比较本身当博士贡献 |
| 文史、法哲及规范论证 | 原始材料/版本、概念与规范前提的取舍如何影响主张，最有力的不同解释或反论是什么，哪些证据或推理能支持修正；不强制统计假设和实验对照 |
| 专业博士与实践研究 | 实践问题及难度相对现行方案何在，创新方案如何形成并评价，使用约束、迁移条件和利益相关者如何影响有效性；完成一个项目不自动等于博士贡献 |

将关键路径与已知资源相连，区分公开可得、实际可用和待申请；区分团队基础与用户实际承担的工作。没有预实验也可规划合理预试与停止/调整节点，学校正式要求已完成的基础须如实满足或标明缺口，不虚构。风险应说明失败后保留哪部分核心问题，不能简单改做不相关的小题。

“材料可选”不等于现实事实可凭空设定。外部可检索事项由skill核实；决定场域可进入性、资料用途或用户工作角色的事实，先拟合理获取路径，在会改变设计的节点向用户核实。无答案时可继续独立阅读和提出条件方案，但不能确认整条关键路径可用。公共数据与公开案例作为备选须重查原问题及贡献，不得静默以更容易拿到的材料替换。

## 5 G4 论证整篇博士论文怎样成立

先有总体问题和推进关系，再映射到学校栏目。可由若干研究、章节或一条贯穿论证组成，数量与样本规模不作为博士标签。逐项说明各部分的独立任务、与前后部分的联系、汇合后如何支持总体贡献；论文集形式也要符合本校要求并交代整合逻辑，不能拼几篇弱相关文章。

将已完成基础、当前开题准备、未来关键研究和整合写作放进真实周期。工作量按材料规模、获取难度、推理/分析深度和依赖估计；不以“必须三项研究/跨地区/多年”制造虚假深度。只适合作为一个前期小研究时明确指出，并提出完整论文架构的候选路线，取得用户决定后展开。

说明论文中不可省掉的关键研究及其依赖：删除某部分后哪项总体主张不再能回答；若删除无影响，检查是否任务堆叠。资源收缩或备选路线启用后，重新判断是否仍有可辩护的博士贡献，不能无限缩小到常规描述却保留博士合格结论。每个核心风险写明何时发现、保留什么问题、需要什么修改或用户选择；不能预设任何失败或阴性结果都自然成为贡献，区分支持、挑战和仍无法判断三类情形。

采用多个研究部分时，说明前部分的哪些发现会改变后部分的材料、方案或解释，怎样整合一致、矛盾与不精确的证据。过程解释不能补成实验未识别的效应，统计差异也不能代替情境解释。无需强制混合方法；已选择组合时，不能只以“相互补充”结束整合论证。

## 6 G5 写出论证密度

综述段落围绕认识或争论展开：主张、相应证据、与另一解释的关系、对本题的具体后果。不能每段只写某作者做了什么，也不能把数页方法操作或伦理说明当作研究深度。背景、综述、问题、设计和贡献须有实际推导联系，篇幅随这些论证需要及正式要求配置。

正文正面说明本题准备推进的认识及论证路线；边界、风险与未来条件放在适当位置，不逐段重复“不保证、不声称”。用已核查的具体工作、概念、材料及研究决策替代“填补空白、丰富理论、提升水平”等空话。可读性润色在实质缺口修复后进行，不靠术语堆叠、扩写或删掉不确定性提升表面成熟度。

### 扩写前先完成关键段落

在G2—G4往返时试写本题最关键的论证，作为正式正文的候选，不是另交一份写作指南。按路径合并或拆分，不规定段数或字数：

| 试写内容 | 段落必须实际完成的工作 | 失败后返回 |
|---|---|---|
| 文献综合与问题提出 | 准确比较最接近工作的回答、依据和条件，推出一个尚值得判断的问题；不能用“研究较少”跳过推导 | G1阅读或G2定位 |
| 核心论证或设计理由 | 说明概念/前提怎样改变材料与分析选择，以及关键证据或推理为什么有助于回答问题；回应有分量的反论 | G3设计，必要时G2 |
| 贡献与整篇论文关系 | 说明拟增加的认识及其后果、各研究部分怎样共同支持、何种结果仍不足以判断；不是并列列出几项工作 | G2贡献或G4整合 |

扩写依据是段落已经形成的推理，不是它包含了多少研究承诺。对照已读原文，判断它是否说明了最接近工作的具体回答、该回答仍不能处理的困难及其重要性、本题拟推进的理由，以及最有力质疑为何尚未使路线失去价值。“拟研究是否有新贡献”“将分析概念如何起作用”不能承担这些连接；断在何处就返回对应阅读、定位或设计，修复后再扩写，不以风险段落放行。

按研究路径选一项最能检验核心连接的有限分析，落实到真实可访问材料或有据的设计比较：例如论证研究重构一条原文推理及其反论，实证研究解释关键比较为何区分目标解释，史料研究分析材料差异如何改变解释。只做足以判断路线是否有根据的工作，不要求完成正式研究、取得预期结果，也不统一要求预实验、证明或案例数量。已经有充分设计依据时直接使用；思想算例可以澄清原则，但不能代替有关现实材料、现行方案或最接近研究的事实判断。

贡献与整体论文关系同样依据当前内容判断：各核心部分分别补足哪项不能由其他部分替代的认识，汇合后推进什么。尚只能支撑一项局部任务时，重构整体路线；增加章节、时间或案例不构成修复。已有用户决定约束路线，不能让失去依据的论证通过；需要实质改变方向时提出有依据的选择并对齐。

审阅时可抽去题目、学校和方法名检查其余文字是否仍适用于大量无关课题；如是，应补本题认识、材料及设计选择，而非换术语。此项只是识别套话的启发，不是自动质量评分，不要求每段套同一格式。

## 7 G5/G6 集中审阅与返回

冻结初稿，从学科定位、方法与证据、整篇论文可行性三个视角分别找最可能动摇方案的实质问题，给出正文位置、依据、影响与修法；这是同一执行者的分视角审阅，不称独立委员会。用户另行授权独立审查时再使用相应能力。

检查：最接近工作是否已回答核心问题；理论与概念是否参与设计；证据是否真能区分关键解释或建立新论证；若主要设想不成立，研究是否仍能形成有意义认识；总体贡献是否超过各小任务并列；重要资源、能力及整合时间是否合理。只要求适合该学科与阶段的证据，不拿最终答辩标准要求开题已取得全部发现。

自审要实际重读最可能推翻主张的已核实材料和对应正文，提出其最有力的质疑并检查回答，不只罗列自己已遵守的要求。核心批评、修订位置和仍未解决项写入现有记录；只写“已优化、合理、充分”不能关闭缺陷。修法应改变依据、论证或研究设计；删掉强主张、增加限制后，须重新判断问题价值与博士潜力。用户确认研究取舍时用简短可理解的内容说明核心问题、贡献依据和最大风险，让其能纠正与自身意图或条件不符之处；认可方案不能替代证据，也不需要额外制造考试或审批。

G1需学术定位有据，G2需博士问题与原创潜力可辩护，G3需设计支撑主张，G4需整体论文路径，G5需论证写实并经上述审阅。仅有格式完整、引文对应、操作规范或用户同意，均不能替代。实质缺口返回对应阶段，修订后同步综述、问题、设计、贡献和进度；无法修复时交代具体未完成事项并继续寻求方案，不标为博士成稿。博士内容状态与Word页面/行政信息状态分别记录。
