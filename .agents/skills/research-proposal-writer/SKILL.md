# 开题报告撰写

## 任务与底线

从确定的选题走到完整报告。用户材料用于提高针对性，不是启动门槛。遵循研究者实际的阅读、聚焦问题、设计、论证、写作和修改过程；工作顺序不等于章节顺序。允许在问题、文献、设计之间往返。

主要服务博士人群。博士任务从开始加载 [博士内容生成与验收](references/doctoral-quality.md)，与学科、方法指导同时执行；核心是有据的原创问题、可辩护的预期贡献、能支撑主张的证据及整篇论文路径。学术博士与专业博士同等覆盖，专业博士再加载 [专业研究与评价](references/professional-doctorate.md)。未知层次或学位类型须核实，不把目标人群当作用户身份；明确的本科硕士任务按其层次处理。

博士内容判断落到最接近研究、证据推理、学科标准及正文，不能用篇幅、方法数量、操作规范或阶段记录替代。学科基础条目不等于该领域博士质量已验证；资源收缩或主张弱化后重新核查贡献，写明局限不能代替修复。

- 必需输入只有选题；可选学校模板、学位层次、导师意见、文献、初稿和研究条件。选题尚未确定时帮助澄清，但不要悄悄替换用户选题。
- 默认关键节点交互；先给有依据的方案、取舍和推荐，再请用户选择。不是向用户索要一套已经完成的研究方案。
- 最终任务是完整开题报告。提纲、检索表和评审意见都是阶段成果，不冒充交付。正在等待关键决定时明确当前进度，后续继续完成。
- 成稿按 [质量控制](references/release-quality.md) 检查内容、证据、设计、一致性及实际文件；影响成稿的缺陷须修复，不能用“有条件成立”或免责声明代替。默认交可编辑Word（.docx），有模板遵循模板，无模板按 [开题文书适配](references/word-format.md) 识别文书形态、层次与专业路径后生成有来源的建议结构和版式；用户明确其他格式时服从其要求。
- 可以设计未来研究；不能编造已完成实验、合作、样本、预实验数据、权限、经费或审批。不保证研究结果、文献穷尽或开题通过。
- 报告同时包含研究内容与适用的基本信息/表单结构。无校表的本科任务默认采用表格式建议版；未知校名、姓名、学号等保留可填写栏，导师意见与签名留空，不因信息未给而省掉整块。信息待补时不称可直接提交，详见上述文书适配。
- 区分用户事实、文献证据、拟议方案、工作假设。未经用户确认的现实条件不能写成既成事实。
- 尊重窄范围修改请求，复用已有决定，不强制重新走完整流程。遵守用户提供的实际课程/学校 AI 使用要求，不伪装独立完成或捏造声明。

## 先读哪些参考

收到选题、学科和专业方向后，按 [学科匹配与执行方案](references/discipline-execution.md) 自动找到主学科及专业路径，组合方法指导，形成包含写法、结构、格式和验收标准的本次执行方案。用户不需要选择内部文件；自动匹配不取消研究方案的关键交互。未给学校格式时采用明确标注的学科建议格式。

开始完整任务时读 [流程与交互](references/workflow.md)、[证据与检索](references/evidence.md)、[学科路由](references/routing.md)。先从 [学科索引](references/disciplines/index.md) 选择适用的学科指导，再组合下表的研究方式指导；同一学科可以采用不同方法，同一方法也不能替代学科论证要求。只读当前相关文件：

| 实际研究方式 | 参考 |
|---|---|
| 文本、历史、解释研究 | [文史分支](references/humanities.md) |
| 问卷、观察、计量与变量关系 | [定量与观察分支](references/quantitative.md) |
| 访谈、案例、田野、行动研究 | [质性分支](references/qualitative.md) |
| 实验、机制、干预验证 | [实验分支](references/experimental.md) |
| 临床、公共卫生、人群研究 | [临床分支](references/clinical.md)，叠加适用定量/质性/实验分支 |
| 算法、系统、工程与计算模拟 | [工程分支](references/engineering.md) |

审阅每个阶段时使用 [验收与返修](references/acceptance.md)，叠加学科与方法标准。开始组织正文及文件交付时读 [写作与交付](references/delivery.md)。内置指导的依据与外推边界见 [来源说明](references/sources.md)、[首轮学科来源](references/disciplines/sources.md) 和 [扩展学科来源](references/disciplines/sources-expanded.md)；它们不是用户学校的规定。索引中延伸或依据不足的子方向须先补证，不能因大类匹配就跳过。超出覆盖时按路由补充，不能机械套用最近分支。

## 执行主线

完整任务执行前读 [实际研究操作](references/research-operations.md)。以下阶段必须落实到检索、关键原文阅读、综合比较、方法和条件核实及论证骨架，并保存简短工作记录；不是按阶段标题直接生成段落。新证据可触发返回，完成写作或日志不等于完成研究准备。

1. **理解选题并自动匹配。** 保留用户给定学科和专业，结合题目匹配主辅指导及具体研究路径，生成写法、结构、格式和验收的执行方案。从已给材料读取要求；仅核实会影响方向的歧义，不重复问已给信息。材料可选。记录来源、用户决定和假设。
2. **定向检索与阅读。** 识别学科及研究路径，读取适用学科指导和方法分支，同时检索问题背景、关键认识/争论及方法先例。根据学科表确定当前阶段的成果、验收依据与用户选择。核验来源与论点；用直接相关工作定位本题，不能只靠通用方法文献或摘要判定研究差异。形成有证据的研究切入点。
3. **对齐研究问题。** 给出可比较的切入方案，指出价值、条件和取舍，请用户确认。题目未变但研究对象/范围有实质变化，也需确认。
4. **形成设计并验收。** 为每个问题建立“目标—内容—材料/数据—方法—判断依据—限制”的对应关系。按分支细化，检查关键操作歧义、主张与证据范围、包括预试在内的工作量、可行性及替代路径，再向用户确认方法和关键条件。
5. **试写关键论证并组织。** 按博士指导先写文献到问题、问题到设计及贡献到整篇论文的关键段落，核查依据和主要反论，不能只列段落提要。论证成立后映射正式模板；没有模板时提出适合课题的结构。呈现有实质内容的提纲、论证重点和建议篇幅供用户确认。用户已授权按推荐执行时合并节点，保留决定记录。
6. **完整撰写、核查、修订。** 按证据写立题与综述，按已确认设计写方案、进度与贡献；逐项应用通用、学科、方法和课题标准。依据质量控制做逐部分内容检查、证据和一致性回查，再集中审阅、修订和复核。呈现全文收取反馈并落实。
7. **成稿交付。** 提供完整正文及已核验参考文献；默认交可编辑Word并核查实际页面，核对文书形态、栏目/附件及逐项版式来源，用户明确其他格式则从其要求。区分已知要求下的成稿、核查未完成草稿和阶段成果。受限草稿不冒称任务已经达成；简述具体限制并继续解决。最终链接成品，不用内部检查表代替报告。

## 交互和通过条件

- 问题只覆盖当前会改变工作的关键决定，通常每轮 1—3 个；选项写明对研究的影响并推荐一个，可自由回答。用户已有答案不再问。
- 不能因用户缺文献、模板或前期成果拒绝开始；检索缺口自行补，条件缺口设计获取路径，研究范围缺口提出选择。
- 关键决定待答时继续独立工作；不要用超时、沉默或预选项代表同意。用户明确授权“按你建议全部完成”后按已说明的建议继续，不反复要确认。
- 科学核查和用户认可分别记录，任一不能替代另一。事实错误不能因用户认可而通过；合理方案也不能默认为用户已接受。
- 阶段结论：通过 / 需返修 / 有条件成立。条件必须可落实且不破坏核心推理；“方法无法回答问题、关键文献未核验、数据条件根本不可行”不能靠条件标签放行。
- 工具或来源受限时提供尽可能完整的草稿及明确限制，不伪称最终验收通过。没有执行过的核查不得标成通过。

## 最小运行记录

长任务在输出目录保存简短工作记录，短任务可留在上下文：课题画像、要求与来源、用户已确认决定、待答问题、证据索引、各阶段状态与返修事项。用户改变方向时标出受影响的文献、方法、提纲和正文，撤销过期结论再修订。不要默认给用户输出这些内部表格。
