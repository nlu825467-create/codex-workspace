# 参考图到原生可编辑 SVG

以下规格继承用户的高还原 SVG 要求。此阶段输出到 `figure.svg` 的内容必须只有有效、完整的 SVG 代码，不混入 Markdown 代码围栏或解释。

## 分析与构建

先查看实际参考图，记录原始尺寸、宽高比、主要元素数量、边界轮廓、视觉中心、留白、对齐、文字位置、HEX/RGB 主辅色、渐变、阴影和光照方向。用同一 viewBox 坐标系重绘，不预先固定为上一张示例图的 1536 × 1024。本图 `design-brief.md` 继续作为视觉依据；参考图存在与其冲突的局部伪影时，按已核对的科学底稿和设计决策修正，并记入质量记录。

分层建议：defs、background、cells/compartments、molecules、decorations、relationships、text。按实际内容命名，每个重要对象有独立 g 和唯一 id，便于移动、着色和修改。跨组的箭头应独立于细胞/蛋白图形；标签不要烘焙进装饰轮廓。

使用 path、rect、circle、ellipse、polygon、line、polyline、text、tspan 等原生元素。允许 defs、gradient、filter、clipPath、mask 与只引用本文件 id 的 use。禁止 image、base64、外部图片链接、canvas、foreignObject 和将位图藏入 pattern、CSS background、data URI 等途径。禁止将整张图变成一条 path，或将文字描边转曲后假称可编辑。

复杂轮廓用多段 Bézier path；细胞膜、蛋白质团簇、手绘标记、图标与装饰纹理分别建组。通过原生渐变、小路径、半透明轮廓与少量原生滤镜重建立体感。比例、位置、边缘、层级和文字的还原优先于虚构微观纹理。避免均匀规则圆球和机械重复符号替代参考图中的不规则形体。

## 可编辑文字

每个文字区域独立分组，例如 `<g id="kinase-label"><text ...>Kinase K</text></g>`。以科学底稿规范标签为准，保留原正确内容、大小写、上下标与符号。字号、字重、颜色、字距、基线、行距、对齐尽量匹配参考图。

优先选择当前主机确实可用且常见的字体，保留合理 fallback。使用 tspan 处理多行、上下标和强调；文字框应留足编辑空间。textLength 仅用于精确匹配时的微调，过度压缩会造成字体失真，不要用它掩盖错误字号。图形箭头可以绘制为 path，但真正的科学文本仍是 text。

## 视觉验收

从最终 SVG 实际渲染 PNG，再与 reference 图检查：

- 宽高比、主体位置、边界、留白和裁切关系。
- 全部节点、箭头方向、抑制端头、区室及证据线型。
- 全部规范标签是否保留、能否读清、有无溢出或重叠。
- 主辅色、渐变和光影是否接近，复杂图形是否有对应细节。
- 图层是否可单独移动，source 中是否没有位图和外部资源。

使用可量化的边界框和位置信息修正比例；SSIM/像素差只能辅助比较，不证明机制准确、文字可编辑或“95%还原”。最多三轮针对明确差异的 SVG 修复，科学错误须先解决。未经实际证据不要宣称数值相似度。

浏览器、Illustrator 和 Figma 对 SVG 滤镜及文字布局的支持有差异。尽量保留真实路径的主体结构；发现兼容问题时调整为路径/渐变替代，不把 SVG 整体扁平化成图片。
