# 论文技术路线图配色

当前默认为黑灰与浅灰的论文风格。这是本技能的默认设计选择，不是所有期刊统一规定。用户给定参考图、期刊说明或指定颜色时，按实际要求调整，不声称某套色值天然符合全部学术出版要求。

## 默认颜色与用途

| 用途 | 色值 |
|---|---|
| 标题与主要文字 | #222222 |
| 说明文字 | #666666 |
| 节点边框与主连接线 | #555555 |
| 阶段背景 | #F7F7F7 |
| 关键产物浅灰填充 | #EFEFEF |
| 次要通道 | #888888 |
| 反馈及条件关系 | #555555，靠位置与标签说明 |

普通节点白底，文字黑灰。判断节点依靠菱形区分，验证依靠清晰分区与名称区分，模型依靠并行位置和文字区分。使用少量加粗突出关键节点，避免大面积深色底白字。浅灰背景只辅助分组，不能承载唯一的数据身份。

academic 默认使用灰度层级；mono 强制白底、黑字、黑线；color 为用户指定的彩色图。自定义layout-spec中的颜色仍能覆盖academic基础设置，模型须主动把默认NodeStyle、nodeStyles、阶段、说明和每条自定义路由改成同一套颜色，不能只改变style字段而遗漏旧彩色对象。

## 用户要求彩色时

选择有限、低饱和且有明确用途的颜色。正文保持接近黑色；文字、形状、位置和标签共同表达类别。检查灰度打印后能否识别所有研究关系，不用红绿对比作为唯一分组信号。参考图使用明确学术色彩时可匹配；不要把鲜艳的演示配色作为默认论文配色。

## 检查

逐图查看浅灰背景、细线、字重是否仍能区分层级。检查实际PPTX中的节点、连接线、阶段标题、条件标签、说明和页脚，避免残留彩色对象。保留用户已经接受的节点位置、画布、关系和构图，配色修改不自动重排。
