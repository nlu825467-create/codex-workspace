# 按最终页面尺寸校准

## 用途与尺寸

先确定用途。用户说明基金申报时按基金处理；期刊投稿按该期刊图稿指南处理，不能把某期刊字号规则推广成基金标准。不清楚用途时可询问，并继续提取研究关系。

用户未给基金模板时，以 A4、图宽160 mm作为可调整的排版假设，不称为基金委规定。模板页边距、图注和其他内容优先。期刊未确定时可以按单栏90 mm、通栏180 mm做诊断，但不能宣称投稿合规。

在 route.appearance 设置 target_width_mm 与 print_profile（funding/journal/general）。原生PPT页面会对应目标毫米宽度；PNG按该宽度和dpi计算像素。显式png_width优先，但核对其DPI物理宽度是否与目标一致。PNG与PPT的物理尺寸不一致时应说明并修正，不能只修改DPI元数据。

## 基金的建议尺度

这是本技能的可读性建议，不是资助机构统一要求。以下全部为插入申请书后的点数：

| 元素 | 建议 |
|---|---|
| 普通节点 | 9–10 pt |
| 阶段标题 | 11–12 pt |
| 辅助说明、关系标签与图例 | 8–9 pt |
| 主连接线 | 0.7–0.9 pt |
| 辅助连接线 | 0.5–0.6 pt |
| 节点边框 | 0.5–0.7 pt |
| 箭头头部 | 中等大小起步，按方向辨识和线宽协调调整 |

增加字号时同步调整节点、行距和路由。保留核心节点和研究关系，将长句凝练成标签，完整说明留在依据及备注中。密度仍过高时分为概览与局部图，不能通过把必要文字压到小字号来强行单页。

## 自定义布局与换算

布局坐标和字号仍用CSS像素。给定画布宽 W、目标宽 M毫米，最终字号或线宽为 `CSS数值 × M/W × 72/25.4` pt；反算CSS数值使用 `目标pt × W/M × 25.4/72`。

layout-spec可配置 frameWidth、edgeWidth、routing[id].width、arrowSize（sm/med/lg）、footerSize/footerHeight/footerY；文字与线宽均在绘制时一同按物理尺寸缩放。不要只增加PNG像素。针对不同用途按需要设定各层字体，不把基金字号变成所有图的默认。

## 交付检查

渲染器会读取最终PPTX，运行 scripts/inspect_print.py，并在内部保存 print-audit.json。它记录真实页面毫米尺寸、各文字点数、线宽和箭头预设。funding模式按本技能建议提示小字、小线和小箭头；journal模式仅测量，不推断具体期刊合规。程序不是印刷审美或机构合规证书。

查看最终PNG，检查标题、节点文字是否被截断、节点容纳、短箭头方向和灰度辨识。在基金用途下，再将图按目标宽度放进A4页面，留出图注，导出PDF并渲染查看（使用可用PDF技能）。此页面校样仅证明页面容纳及该缩放下的可视效果，不能代替实体打印和用户模板验证。可给用户交付A4校样方便按100%尺寸查看或打印；不要只在放大预览下验收。

用户以后修改图宽、字体或节点后，应重新运行尺寸检查和页面校样。新宽度会改变所有最终点数，不能沿用旧的检查结论。
